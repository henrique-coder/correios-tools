# Correios Wizard

Extensão para Chrome que otimiza tarefas operacionais nos Correios.

## Instalação

Disponível na [Chrome Web Store](https://chromewebstore.google.com/).

## Funcionalidades

- Automação de tarefas repetitivas no SRO Web
- Interface otimizada para operações diárias

## Estrutura

```
src/
├── manifest.json    # Configuração da extensão
├── background.js    # Service worker
├── content.js       # Script de conteúdo
├── injected.js      # Script injetado na página
└── icons/           # Ícones da extensão
```
